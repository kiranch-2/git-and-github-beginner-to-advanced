# Git & GitHub Learning

This repository contains my practical learning notes for Git and GitHub using Ubuntu Terminal.

## Purpose

The purpose of this repository is to learn Git and GitHub step by step through practical exercises.

## Topics Covered

- Git installation on Ubuntu
- Understanding Git and GitHub
- Git repositories
- Cloning a repository
- Working with files and folders
- Renaming files and folders
- Git status
- Git add
- Git commit
- Git push
- Git pull
- Branches
- Basic Git troubleshooting
- Useful Git commands

## Learning Approach

Each topic is documented with:

- Command
- Meaning of the command
- Step-by-step usage
- Practical example
- Important notes
